## Project Description
I built a custom alarm clock using a Raspberry Pi and buzzers, programmed to play one of 30 randomly selected songs. This required me to learn web scraping to source the music data.
 You use a rotary encoder to control to set the time. It then plays a random song once the time is up.
## Built with
- Python
- Raspberry Pi
- Sunfounder Electronics Kit
